Japan Cycling Map 2027

This map uses Google Maps for visuals and free OpenStreetMap data for road routing — no Directions API or billing required. You only need a free Maps JavaScript API key.

1
Go to console.cloud.google.com and sign in with your Google account.
2
Click Select a project → New Project. Name it anything (e.g. Japan Trip Map). Click Create.
3
In the left menu go to APIs & Services → Library. Search for and enable: Maps JavaScript API  (that's the only one needed)
4
Go to APIs & Services → Credentials → Create Credentials → API Key. Copy your key and paste it below.
Road routing uses the free OSRM / OpenStreetMap engine — no billing required on your account.

Your key is saved in this browser only and never sent anywhere except Google Maps.
